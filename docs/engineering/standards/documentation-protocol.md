# Documentation Update Standard

Always update `CURRENT_STATE.md`, the relevant project, a task record, and the
current journal entry. Add ADR, experiment, failure, metrics, model, roadmap,
release, book, or publication updates only when triggered by the work.

Every implementation report includes “Documentation impact” with updated and
not-required records plus rationale. Validate Markdown links, YAML/JSON, and
diff scope before review.
