# Data Pipelines

- Churn: validate → clean → engineer features → stratified 60/20/20 split →
  compare/tune → persist pipeline and reports.
- Housing: load/download → split → compare regressors → persist model/plots.
- Sentiment: load/download → TF-IDF → compare classifiers → persist pipeline.
- Trendyol search: validate/group split → feature/retrieval index → versioned
  evaluation → governed artifacts → bounded runtime service.
- Midterm: load → schema compatibility → clean/analyze/visualize → notebook.
- Profile: inventory → schema/quality/statistical summaries → reports.
- Copilot: repository allowlist → documents/chunks → deterministic retrieval →
  extractive answer/citations → official evaluation.
