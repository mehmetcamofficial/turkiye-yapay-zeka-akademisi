# Model Evaluation

Predictive projects report held-out task metrics and preserve comparison
artifacts. Trendyol research separates classification, candidate retrieval, and
reranking metrics; promotion decisions include uncertainty and runtime scope.
Copilot uses file retrieval and grounded-answer metrics, not predictive accuracy.

Never compare metrics with different tasks or denominators as if they measured
the same capability. Current confirmed values are in `../../metrics/history.json`.
