# Metric Definitions

- Accuracy/precision/recall/F1/ROC AUC: predictive classification metrics.
- MAE/MSE/RMSE/R²: regression metrics.
- Recall@K: proportion of labeled relevant candidates recovered by K.
- NDCG@K: discounted graded ranking gain normalized by ideal order.
- MRR: mean reciprocal rank of the first relevant result.
- Retrieval@5: applicable Copilot questions with an accepted file in the first
  five unique files, divided by applicable questions.
- Citation validity: citations resolving inside allowed repository boundaries.
- Citation precision: citations supporting the answer under canonical checks.
- Required concept recall: matched required concepts / required concepts.
- Unsupported claim rate: unsupported claims / evaluated claims.
