# Glossary

- **geçit / gate**: a quality threshold that controls acceptance.
- **envanter / inventory**: a bounded listing of data or repository assets.
- **aday üretimi / candidate generation**: retrieval stage before reranking.
- **Retrieval@5**: fraction of applicable questions whose accepted file is in
  the first five unique retrieved files.
- **RRF**: reciprocal rank fusion of ranked lists.
- **Group C**: local, untracked research tooling outside public commit scope.
- **canonical**: the protected evaluation path used for release decisions.
- **not promoted**: researched but not selected for the runtime policy.
