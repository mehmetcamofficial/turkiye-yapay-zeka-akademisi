# Engineering Knowledge System

This directory is the canonical handbook, journal, research index, decision
archive, and publication evidence map for the complete repository.

## Start here

- Project identity and history: `project/`
- Architecture: `architecture/`
- Project records: `projects/index.md`
- Models and datasets: `models/` and `data/`
- Interfaces: `interfaces/`
- Tasks, ADRs, experiments, failures, releases: `engineering/`
- Research registry: `research/`
- Evaluation methodology: `evaluation/`
- Journal and prompts: `journal/` and `prompts/`
- Publication preparation: `publication/`
- Reusable schemas: `templates/`

## V1.1 views and generated evidence

- Living book: [PROJECT_BOOK.md](../PROJECT_BOOK.md)
- Human dashboard: [STATUS.md](../STATUS.md)
- Timeline and lessons: [TIMELINE.md](../TIMELINE.md), [LESSONS.md](../LESSONS.md)
- Collaboration and decisions: [AI_COLLABORATION.md](../AI_COLLABORATION.md),
  [DECISION_TREE.md](../DECISION_TREE.md)
- Architecture evolution: [architecture-evolution.md](architecture/architecture-evolution.md)
- Generated graph: [knowledge-graph-summary.md](architecture/diagrams/generated/knowledge-graph-summary.md)
- Generated metrics: [metrics/dashboard.md](../metrics/dashboard.md)
- Asset manifest: [assets/manifest.yaml](assets/manifest.yaml)

Evidence confidence is one of `confirmed`, `strong`, `partial`, or `unknown`.
An inference must be labeled in prose and must link to its evidence.
