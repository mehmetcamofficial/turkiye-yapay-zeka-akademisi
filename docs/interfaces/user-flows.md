# User Flows

1. Select language and navigation section.
2. Inspect project status, metrics, evidence, and limitations.
3. Run bounded local inference where artifacts exist.
4. Search repository resources and jump to project/notebook/experiment pages.
5. Ask Copilot a repository question and inspect citations.
6. Review model registry, artifact health, policy comparison, and evaluation.

Downloads include prediction CSVs and tracked notebooks where pages explicitly
offer them. Missing artifacts should render controlled unavailable states.
