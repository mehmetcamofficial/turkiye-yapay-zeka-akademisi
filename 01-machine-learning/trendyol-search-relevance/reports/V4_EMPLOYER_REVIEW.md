# V4 Employer Review

Recruiters can see one guided system spanning lexical/semantic retrieval, RRF fusion, candidate provenance, unchanged relevance scoring, isolated experimental ranking and safe fallbacks. Technical reviewers can inspect versioned contracts, deterministic ordering, fingerprints, timings and paired evidence.

Search engineers can distinguish candidate recall from reranking metrics and see why V1/ranker policies were rejected. Platform engineers can inspect the OpenMP process boundary, persistent worker lifecycle, target budgets, degraded states and cache counts. Product reviewers see bounded scope, honest latency and governance rather than a production-deployment claim.
